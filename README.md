# laravel-online-vs-offline-mumbai-landing

A fun, scroll stopping single page landing site answering **"Laravel Online Course vs Offline Course: Which Is Better in Mumbai"**, built around a versus style split screen hero and an honest scorecard comparing both formats category by category.

## Highlights

- Signature visual: a versus style split screen hero, online on one side, offline on the other, with a pulsing VS badge in the center.
- A second signature element: an honest scorecard comparing both formats across flexibility, cost, accountability, debugging support and more.
- Distinct palette: warm cream background, Laravel red, cool blue for the online side and warm amber for the offline side, paired with Manrope, Inter and Fira Code typography, different from any other page in this series.
- Fully responsive: the split screen gracefully stacks into a single column on smaller devices, and the scorecard remains readable on mobile.
- Fully clickable cards: the course and all three blog links are wrapped as single clickable cards throughout the page and footer.
- Zero dependencies: plain HTML and CSS, works out of the box on GitHub Pages.

## Run it locally

```bash
git clone https://github.com/<your-username>/laravel-online-vs-offline-mumbai-landing.git
cd laravel-online-vs-offline-mumbai-landing
open index.html
```

## Deploy on GitHub Pages

1. Push this repo to GitHub.
2. Go to Settings, then Pages.
3. Under "Build and deployment", set Source to the main branch, root folder.
4. Save. Your page will be live at `https://<your-username>.github.io/laravel-online-vs-offline-mumbai-landing/`.

## Tech Stack

- HTML5, CSS3 (custom properties, grid and flexbox, keyframe animations)
- Google Fonts: Manrope, Inter, Fira Code
